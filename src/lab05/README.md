# Лабораторная работа №5 - Функции как аргументы. Стратегии и делегаты.

## 1. Цель работы
Освоить передачу функций как аргументов, научиться применять встроенные функции высшего порядка (`map`, `filter`, `sorted`), разобраться с паттерном «Стратегия» и реализовать его на Python, освоить `lambda`-выражения.

## 2. Реализованные функции и стратегии

### Функции для сортировки

| Функция | Описание |
|---------|----------|
| `by_hostname` | Сортировка по имени хоста |
| `by_load` | Сортировка по нагрузке (возрастание) |
| `by_load_desc` | Сортировка по нагрузке (убывание) |

### Функции для фильтрации

| Функция | Описание |
|---------|----------|
| `is_active` | Только активные серверы |
| `is_web_server` | Только веб-серверы |

### Фабрика функций

| Фабрика | Описание |
|---------|----------|
| `has_high_load(threshold)` | Формирует фильтр для нагрузки выше заданного порога |

### Callable-объект (паттерн Стратегия)

| Класс | Описание |
|-------|----------|
| `LoadSortStrategy` | Стратегия сортировки по нагрузке с параметром `reverse` |

### Методы коллекции (расширение из ЛР-2)

| Метод | Описание |
|-------|----------|
| `sort_by(key_func, reverse)` | Сортировка по переданной функции |
| `filter_by(predicate)` | Фильтрация по переданной функции |
| `apply(func)` | Применение функции ко всем элементам |

## 4. Вывод

В ходе лабораторной работы были изучены следующие концепции:

- **Передача функций как аргументов** — сортировка, фильтрация, применение к элементам
- **lambda-выражения** — создание анонимных функций на месте
- **Функции высшего порядка** — `map`, `filter`, `sorted`
- **Фабрики функций** — построение функций с параметрами через замыкания
- **Паттерн «Стратегия»** — взаимозаменяемые функции и callable-объекты
- **Цепочки операций** — последовательное применение `filter → sort → apply`
- **Callable-объекты** — классы с методом `__call__` как стратегии поведения
